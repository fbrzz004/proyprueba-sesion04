# proyprueba

Proyecto de login de la sesión 03, usado en el laboratorio de tres ramas de GitHub.

## Archivos

- `index.html`: estructura del formulario.
- `styles.css`: apariencia y diseño adaptable.
- `script.js`: validación y mostrar/ocultar contraseña.

## Uso

Abrir `index.html` en un navegador o publicar la carpeta con Live Server.
